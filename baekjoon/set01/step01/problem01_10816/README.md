# 백준 10816번 - 숫자 카드 2

## 문제 설명

가지고 있는 숫자 카드 N장과 확인할 정수 M개가 주어집니다. 각 정수가 적힌 카드를 몇 장 가지고 있는지 입력된 순서대로 출력하는 문제입니다. 같은 숫자가 여러 번 나올 수 있으며, 가지고 있지 않은 숫자는 0을 출력합니다.

예를 들어 카드가 `1 2 2 3 3 3`이고 확인할 숫자가 `3 1 4`라면, 결과는 `3 1 0`입니다.

## 풀이 방법 1 - HashMap

`HashMap<Integer, Integer>`에 숫자별 카드 개수를 저장합니다.

1. 카드의 숫자를 하나씩 읽어 해당 숫자의 개수를 1씩 증가시킵니다.
2. 확인할 숫자의 개수를 맵에서 조회합니다. 없는 숫자는 0으로 처리합니다.
3. 결과를 `StringBuilder`에 모아 한 번에 출력합니다.

해시맵의 삽입과 조회가 평균 O(1)이므로, 전체 시간 복잡도는 평균 **O(N + M)**입니다.

## 풀이 방법 2 - 정렬과 이분 탐색

카드 배열을 정렬한 뒤, 이분 탐색으로 각 숫자가 등장하는 구간의 시작과 끝을 찾습니다.

1. `Arrays.sort(arr)`로 카드 배열을 오름차순 정렬합니다.
2. `lowerBound(arr, num)`으로 `num` 이상인 첫 원소의 인덱스를 찾습니다.
3. `upperBound(arr, num)`으로 `num`보다 큰 첫 원소의 인덱스를 찾습니다.
4. `upperBound - lowerBound`로 해당 숫자의 개수를 구하고, 결과를 `StringBuilder`에 모아 출력합니다.

예를 들어 정렬된 배열이 `1 2 2 3 3 3`이고 찾는 숫자가 `2`라면, `lowerBound`는 1, `upperBound`는 3이므로 개수는 `3 - 1 = 2`입니다. 찾는 숫자가 없다면 두 경계가 같아 결과는 0입니다.

두 함수는 탐색 범위를 `[left, right)`로 두고, 처음에는 `left = 0`, `right = arr.length`로 설정합니다. 조건을 만족하는 원소가 없으면 배열 길이를 반환합니다.

정렬에 O(N log N), 숫자 M개를 조회하는 데 O(M log N)이 걸리므로, 전체 시간 복잡도는 **O(N log N + M log N)**입니다.
