# 백준 9012번 - 괄호

## 문제 설명

여러 개의 괄호 문자열이 주어지면, 각 문자열이 올바른 괄호 문자열(VPS)인지 판단하는 문제입니다. 모든 여는 괄호 `(`가 닫는 괄호 `)`와 순서에 맞게 짝을 이루면 `YES`, 그렇지 않으면 `NO`를 출력합니다.

예를 들어 `(()())`는 `YES`이고, `())(`는 괄호의 개수가 같아도 짝이 맞는 순서가 아니므로 `NO`입니다.

## 풀이 방법

`Main.java`에서는 `Stack<Character>`에 아직 짝을 찾지 못한 여는 괄호를 저장합니다.

1. 각 문자열을 검사하기 전에 스택을 비웁니다.
2. 여는 괄호 `(`를 만나면 스택에 넣습니다.
3. 닫는 괄호 `)`를 만나면 스택에서 여는 괄호 하나를 꺼냅니다. 스택이 비어 있다면 짝이 없으므로 검사를 중단합니다.
4. 검사 도중 문제가 없었고 마지막에 스택도 비어 있다면 `YES`, 그렇지 않으면 `NO`를 출력합니다. 결과는 `StringBuilder`에 모아 한 번에 출력합니다.

각 문자를 한 번씩 확인하므로, 문자열 하나의 길이가 L일 때 시간 복잡도는 **O(L)**입니다. 전체 시간 복잡도는 입력된 모든 문자열의 길이 합에 비례합니다.
