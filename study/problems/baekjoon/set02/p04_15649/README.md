
## 1. 문제 내용

**백준 15649번 - N과 M (1)**

자연수 N과 M이 주어졌을 때, 1부터 N까지의 자연수 중에서 중복 없이 M개를 선택하여 만들 수 있는 모든 수열을 구하는 문제.

- 입력: 자연수 N, M (1 ≤ M ≤ N ≤ 8)
- 출력: 길이가 M인 모든 수열을 사전순으로 출력
- 같은 숫자를 중복해서 선택할 수 없음
- 숫자의 순서가 다르면 서로 다른 수열로 취급

## 2. 문제 등급

- **백준 실버 3 (Silver III)**

## 3. 문제 유형

- 백트래킹 (Backtracking)
- 깊이 우선 탐색 (DFS)
- 순열 (Permutation)

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력

**입력**
```text
1 1
```

**예상 출력**
```text
1
```

### 테스트 케이스 2 - 일반 입력

**입력**
```text

```

```text

```
