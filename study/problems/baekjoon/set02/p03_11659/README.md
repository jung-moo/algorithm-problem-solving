
## 1. 문제 내용

**백준 11659번 - 구간 합 구하기 4**

N개의 정수가 주어졌을 때, M개의 구간에 대해 각 구간에 포함된 정수의 합을 구하는 문제.

**입력 조건**
- 첫째 줄에 정수의 개수 N과 구간 합을 구하는 횟수 M이 주어진다.
- 둘째 줄에 N개의 정수가 주어진다.
- 이후 M개의 줄에 구간을 나타내는 두 정수 i, j가 주어진다.
- 1 ≤ N ≤ 100,000
- 1 ≤ M ≤ 100,000
- 1 ≤ i ≤ j ≤ N
- 각 정수는 1 이상 1,000 이하이다.

**출력 조건**
- 각 구간 [i, j]에 포함된 정수의 합을 한 줄씩 출력한다.

## 2. 문제 등급

- **실버 3 (Silver III)**

## 3. 문제 유형

- 누적 합 (Prefix Sum)
- 구간 합 (Range Sum)
