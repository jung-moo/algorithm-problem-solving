## 문제 내용

**백준 1654번 - 랜선 자르기**

길이가 서로 다를 수 있는 K개의 랜선을 같은 길이로 잘라 N개 이상의 랜선을 만들려고 한다.

기존 랜선을 자르거나 남은 부분을 버릴 수 있지만, 서로 연결할 수는 없다.

N개 이상의 랜선을 만들 수 있는 랜선의 최대 길이를 구하는 문제이다.

### 입력

- 첫 번째 줄에 기존 랜선의 개수 K와 필요한 랜선의 개수 N이 주어진다.
- 이후 K개의 줄에 각 랜선의 길이가 주어진다.
- 1 ≤ K ≤ 10,000
- 1 ≤ N ≤ 1,000,000
- K ≤ N
- 랜선의 길이는 2³¹ - 1 이하의 자연수이다.
- N개 이상의 랜선을 만들 수 있는 경우만 입력으로 주어진다.

### 출력

- N개 이상의 랜선을 만들 수 있는 최대 길이를 출력한다.

## 문제 등급

- 실버 2 (Silver II)

## 문제 유형

- 이분 탐색 (Binary Search)
- 결정 알고리즘 (Parametric Search)

## 테스트 케이스

### 테스트 케이스 1 — 일반적인 경우

입력
```
4 11
802
743
457
539
```

예상 출력
```
200
```

### 테스트 케이스 2 — 정답이 최소 길이인 경우

입력
```
3 9
2
3
4
```

예상 출력
```
1
```

### 테스트 케이스 3 — 최대 길이 및 정수 오버플로우 검증

입력
```
3 3
2147483647
2147483647
2147483647
```

예상 출력
```
2147483647
```
