# 백준 1874 - 스택 수열

## 1. 문제 내용

1부터 N까지의 정수를 오름차순으로 스택에 PUSH하면서, POP 연산을 통해 주어진 수열을 만들 수 있는지 판단하는 문제다.

- PUSH는 반드시 1부터 N까지 오름차순으로 수행해야 한다.
- POP은 스택의 가장 위에 있는 숫자만 꺼낼 수 있다.
- 주어진 수열을 만들 수 있다면 PUSH(`+`)와 POP(`-`) 연산을 한 줄씩 출력한다.
- 수열을 만들 수 없다면 `NO`를 출력한다.

**입력 조건**
- 첫째 줄에 정수 N이 주어진다. (1 ≤ N ≤ 100,000)
- 다음 N개의 줄에 1부터 N까지의 정수가 중복 없이 하나씩 주어진다.

**출력 조건**
- 수열을 만들 수 있다면 연산 순서대로 `+` 또는 `-`를 출력한다.
- 수열을 만들 수 없다면 `NO`를 출력한다.

## 2. 문제 등급

- **백준 실버 2 (Silver II)**

## 3. 문제 유형

- 자료구조 (Data Structure)
- 스택 (Stack)
