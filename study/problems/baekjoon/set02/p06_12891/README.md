## 1. 문제 내용

**백준 12891번 - DNA 비밀번호**

https://www.acmicpc.net/problem/12891

'A', 'C', 'G', 'T'로 구성된 DNA 문자열이 주어진다.

이 문자열에서 길이가 P인 연속된 부분 문자열을 비밀번호로 사용할 때, 각 문자의 최소 등장 횟수 조건을 만족하는 비밀번호의 개수를 구하는 문제다.

**입력 조건**
- 첫째 줄: DNA 문자열 길이 S, 비밀번호 길이 P
- 둘째 줄: 길이가 S인 DNA 문자열
- 셋째 줄: A, C, G, T의 최소 등장 횟수
- 1 ≤ P ≤ S ≤ 1,000,000
- 각 문자의 최소 등장 횟수는 0 이상이며, 네 값의 합은 P 이하이다.

**출력 조건**
- 조건을 만족하는 부분 문자열의 개수를 출력한다.
- 동일한 문자열이라도 시작 위치가 다르면 각각 계산한다.

## 2. 문제 등급

**실버 2 (Silver II)**

## 3. 문제 유형

- 슬라이딩 윈도우 (Sliding Window)
- 문자열 (String)
- 구현 (Implementation)

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력

**입력**
```text

T
0 0 0 1
```

**예상 출력**
```text
1
```

**입력**

```text
1
```
