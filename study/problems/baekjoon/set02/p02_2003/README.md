
## 1. 문제 내용
- **문제 번호:** 백준 2003번 - 수들의 합 2
- **문제 설명:**
    - N개의 자연수로 이루어진 수열이 주어진다.
    - 연속된 부분 수열의 합이 M이 되는 경우의 수를 구한다.
    - 수열의 모든 원소는 자연수이며, 각 원소는 10,000 이하이다.

- **입력 조건:**
    - 첫째 줄에 N(1 ≤ N ≤ 10,000), M(1 ≤ M ≤ 300,000,000)이 주어진다.
    - 둘째 줄에 N개의 자연수가 주어진다.

- **출력 조건:**
    - 연속된 부분 수열의 합이 M이 되는 경우의 수를 출력한다.

## 2. 문제 등급
- **실버 4 (Silver IV)**

## 3. 문제 유형
- **투 포인터 (Two Pointers)**

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력
**입력**
```text
1 3
3
```

**예상 출력**
```text
1
```

### 테스트 케이스 2 - 일반적인 입력
**입력**
```text
5 3
1 2 1 1 1
```

**예상 출력**
```text
3
```

### 테스트 케이스 3 - 큰 원소가 포함된 입력
**입력**
```text
8 3
100 1 2 100 3 1 1 1
```

**예상 출력**
```text
3
```
