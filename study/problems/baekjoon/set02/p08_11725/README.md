
## 1. 문제 내용

**백준 11725번 - 트리의 부모 찾기**

https://www.acmicpc.net/problem/11725

루트가 1번인 트리가 주어졌을 때, 각 노드의 부모 노드를 구하는 문제이다.

- 노드의 개수 `N`은 2 이상 100,000 이하이다.
- `N - 1`개의 간선 정보가 주어진다.
- 간선은 방향이 없으며, 입력 순서로 부모와 자식을 구분할 수 없다.
- 트리의 루트는 항상 1번 노드이다.
- 2번 노드부터 N번 노드까지 각 노드의 부모 번호를 한 줄씩 출력한다.

## 2. 문제 등급

- **실버 2 (Silver II)**

## 3. 문제 유형

- **트리 (Tree)**
- **너비 우선 탐색 (BFS)**
- 깊이 우선 탐색 (DFS)
- 그래프 탐색 (Graph Traversal)

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력

**입력**
```text
2
1 2
```

**예상 출력**
```text
1
```
