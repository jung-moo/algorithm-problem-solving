# 백준 2579 - 계단 오르기

## 1. 문제 내용

계단마다 점수가 주어질 때, 다음 규칙을 지키면서 마지막 계단까지 올라가 얻을 수 있는 최대 점수를 구하는 문제다.

**이동 규칙**
- 한 번에 1계단 또는 2계단을 올라갈 수 있다.
- 연속된 3개의 계단을 모두 밟을 수 없다.
- 마지막 계단은 반드시 밟아야 한다.
- 시작점은 계단에 포함되지 않는다.

**입력 조건**
- 첫째 줄에 계단의 개수 N이 주어진다. (1 ≤ N ≤ 300)
- 둘째 줄부터 N개 줄에 걸쳐 각 계단의 점수가 주어진다.
- 각 계단의 점수는 10,000 이하의 자연수다.

**출력 조건**
- 규칙을 지키면서 얻을 수 있는 최대 점수를 출력한다.

## 2. 문제 등급

- **실버 3 (Silver III)**

## 3. 문제 유형

- 다이나믹 프로그래밍(DP)
