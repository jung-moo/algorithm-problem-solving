## 문제 설명

- **문제 등급:** 실버 2

배추밭에 배추흰지렁이를 배치하여 배추를 해충으로부터 보호하려고 한다.

배추흰지렁이는 상하좌우로 인접한 배추 사이를 이동할 수 있으며, 하나의 연결된 배추 그룹에는 지렁이 한 마리만 있으면 된다.

배추밭의 크기와 배추가 심어진 좌표가 주어졌을 때, 모든 배추를 보호하기 위해 필요한 최소 배추흰지렁이의 수를 구하는 문제이다.

### 입력 조건

- 첫 번째 줄에 테스트 케이스의 개수 `T`가 주어진다.
- 각 테스트 케이스의 첫 번째 줄에는 `M N K`가 주어진다.
    - `M`: 배추밭의 가로 길이 (1 ≤ M ≤ 50)
    - `N`: 배추밭의 세로 길이 (1 ≤ N ≤ 50)
    - `K`: 배추가 심어진 위치의 개수 (1 ≤ K ≤ 2500)
- 이후 `K`개의 줄에 배추의 좌표 `X Y`가 주어진다.
    - `0 ≤ X < M`
    - `0 ≤ Y < N`
- 동일한 좌표에 배추가 중복으로 심어지는 경우는 없다.

### 출력 조건

각 테스트 케이스마다 필요한 최소 배추흰지렁이의 수를 한 줄에 하나씩 출력한다.
