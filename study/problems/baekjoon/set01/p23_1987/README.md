## 1. 문제 내용

- **문제 번호:** 백준 1987번 - 알파벳
- **문제 설명:**
    - R×C 크기의 보드가 주어지며, 각 칸에는 대문자 알파벳이 적혀 있다.
    - 말은 좌측 상단 `(0, 0)`에서 출발한다.
    - 상하좌우로 한 칸씩 이동할 수 있다.
    - 지금까지 지나온 경로에서 사용한 알파벳은 다시 사용할 수 없다.
    - 말이 이동할 수 있는 최대 칸 수를 구한다.
- **입력 조건:**
    - 첫째 줄에 보드의 크기 R, C가 주어진다. (1 ≤ R, C ≤ 20)
    - 다음 R개의 줄에 C개의 대문자 알파벳이 주어진다.
- **출력 조건:**
    - 말이 방문할 수 있는 최대 칸 수를 출력한다.
    - 시작 위치도 방문 칸 수에 포함한다.

## 2. 문제 등급
- **골드 4 (Gold IV)**

## 3. 문제 유형
- **그래프 탐색 (Graph Traversal)**
- **깊이 우선 탐색 (DFS)**
- **백트래킹 (Backtracking)**

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력 및 종료 조건

**입력**
```text
1 1
A
```

**예상 출력**
```text
1
```
