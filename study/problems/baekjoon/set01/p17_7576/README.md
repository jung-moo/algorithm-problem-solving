# 백준 7576번 - 토마토

- **문제 등급:** 골드 5

## 문제 내용

가로 `M`, 세로 `N`인 상자에 토마토가 들어 있다.

익은 토마토와 상하좌우로 인접한 익지 않은 토마토는 하루가 지나면 익는다. 대각선으로는 영향을 주지 않으며, 토마토가 없는 칸도 있다.

모든 토마토가 익는 데 필요한 **최소 일수**를 구한다.

- `1`: 익은 토마토
- `0`: 익지 않은 토마토
- `-1`: 토마토가 없는 칸
- 처음부터 모두 익었다면 `0`을 출력한다.
- 모두 익을 수 없다면 `-1`을 출력한다.

## 테스트 케이스

### 테스트 케이스 1 - 중앙에서 확산

**입력**

```text
3 3
0 0 0
0 1 0
0 0 0
```

**출력**

```text
2
```

### 테스트 케이스 2 - 익을 수 없는 토마토가 존재

**입력**

```text
3 3
1 -1 0
-1 -1 -1
0 -1 0
```

**출력**

```text
-1
```
