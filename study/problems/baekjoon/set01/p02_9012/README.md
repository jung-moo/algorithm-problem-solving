# 백준 9012번 - 괄호

## 문제 설명

여러 개의 괄호 문자열이 주어지면, 각 문자열이 올바른 괄호 문자열(VPS)인지 판단하는 문제입니다. 모든 여는 괄호 `(`가 닫는 괄호 `)`와 순서에 맞게 짝을 이루면 `YES`, 그렇지 않으면 `NO`를 출력합니다.

예를 들어 `(()())`는 `YES`이고, `())(`는 괄호의 개수가 같아도 짝이 맞는 순서가 아니므로 `NO`입니다.

## 풀이 방법 - Stack

각 문자를 한 번씩 확인하므로, 문자열 하나의 길이가 L일 때 시간 복잡도는 **O(L)**입니다. 전체 시간 복잡도는 입력된 모든 문자열의 길이 합에 비례합니다.
