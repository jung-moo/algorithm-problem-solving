# 백준 1920번 - 수 찾기

## 문제 설명

N개의 정수가 주어졌을 때, 이후 입력되는 M개의 정수가 처음 주어진 수들에 포함되어 있는지 확인하는 문제입니다. 각 정수가 존재하면 `1`, 존재하지 않으면 `0`을 입력된 순서대로 한 줄씩 출력합니다. 같은 수가 여러 번 등장하더라도 개수가 아닌 존재 여부만 판단합니다.

### 입력

1. 첫째 줄에 정수의 개수 N이 주어집니다. (1 ≤ N ≤ 100,000)
2. 둘째 줄에 N개의 정수가 주어집니다.
3. 셋째 줄에 확인할 정수의 개수 M이 주어집니다. (1 ≤ M ≤ 100,000)
4. 넷째 줄에 확인할 M개의 정수가 주어집니다.

### 예시

입력:

```text
5
4 1 5 2 3
5
1 3 7 9 5
```

출력:

```text
1
1
0
0
1
```

`1`, `3`, `5`는 처음 주어진 수들에 포함되어 있고, `7`, `9`는 포함되어 있지 않습니다.

## 풀이 방법 1 - 정렬과 이분 탐색

[left, right] 방식
정렬에 O(N log N), 정수 M개를 탐색하는 데 O(M log N)이 걸리므로 전체 시간 복잡도는 **O(N log N + M log N)**입니다.
입력 배열을 저장하는 데 **O(N)**의 공간이 필요하며, 이분 탐색 자체는 **O(1)**의 추가 공간을 사용합니다.

## 풀이 방법 2 - HashSet

집합은 중복된 값을 하나만 저장하지만, 이 문제에서는 개수가 아닌 존재 여부만 필요하므로 결과에 영향을 주지 않습니다. 정렬과 직접 구현한 탐색 함수 없이 조회할 수 있습니다.

해시 집합의 삽입과 조회는 평균 O(1)이므로 전체 시간 복잡도는 평균 **O(N + M)**입니다. 서로 다른 정수가 최대 N개 저장되므로 집합에 필요한 공간은 **O(N)**입니다.
