
# 백준 9375번 - 패션왕 신해빈

## 1. 문제

해빈이는 같은 종류의 의상을 최대 하나씩 착용할 수 있으며, 최소 하나 이상의 의상을 착용해야 한다.

의상의 이름과 종류가 주어졌을 때, 서로 다른 의상 조합의 개수를 구한다.

**입력**

- 첫째 줄에 테스트 케이스의 수가 주어진다.
- 각 테스트 케이스의 첫째 줄에 의상의 수 N이 주어진다. (0 ≤ N ≤ 30)
- 다음 N개의 줄에 의상의 이름과 종류가 공백으로 구분되어 주어진다.
- 의상의 이름은 모두 다르며, 이름과 종류는 길이 1 이상 20 이하의 소문자 또는 `_`로 이루어진 문자열이다.

**출력**

- 각 테스트 케이스마다 가능한 서로 다른 의상 조합의 개수를 한 줄에 출력한다.

## 2. 풀이 방법

**HashMap을 이용한 의상 종류별 개수 집계와 조합 계산**을 사용

### 시간 복잡도

테스트 케이스당 **평균 O(N)**이다.

- N: 전체 의상의 개수
- K: 서로 다른 의상 종류의 개수

HashMap에 N개의 의상을 저장하는 데 평균 O(N)이 걸린다.

이후 HashMap에 저장된 K개의 의상 종류를 순회하며 조합의 개수를 계산하는 데 O(K)가 걸린다.

따라서 전체 시간 복잡도는 **O(N + K) = O(N)**이다.

K는 항상 N 이하이기 때문이다.

### 공간 복잡도

테스트 케이스당 **O(K)**이다.

HashMap에 서로 다른 의상 종류 K개와 각 종류의 의상 개수를 저장하기 때문이다.
