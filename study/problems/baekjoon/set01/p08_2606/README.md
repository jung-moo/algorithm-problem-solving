# 백준 2606번 - 바이러스

## 1. 문제

한 컴퓨터가 바이러스에 감염되면 네트워크를 통해 연결된 모든 컴퓨터도 감염된다.

컴퓨터의 수와 서로 연결된 컴퓨터 쌍이 주어졌을 때, 1번 컴퓨터를 통해 바이러스에 감염되는 컴퓨터의 수를 구한다.

**입력**

- 첫째 줄에 컴퓨터의 수 N이 주어진다. (1 ≤ N ≤ 100)
- 컴퓨터에는 1번부터 N번까지 번호가 붙어 있다.
- 둘째 줄에 네트워크상에서 직접 연결된 컴퓨터 쌍의 수 M이 주어진다.
- 다음 M개의 줄에 직접 연결된 두 컴퓨터의 번호가 주어진다.

**출력**

- 1번 컴퓨터를 제외하고, 1번 컴퓨터를 통해 바이러스에 감염되는 컴퓨터의 수를 출력한다.
