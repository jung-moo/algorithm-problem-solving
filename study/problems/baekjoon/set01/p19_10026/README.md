# [백준 10026] 적록색약

- **문제 등급:** 골드 5

## 1. 문제 내용

N×N 크기의 그리드에 R(빨강), G(초록), B(파랑) 중 하나의 색이 칠해져 있다.

상하좌우로 인접한 칸의 색이 같으면 하나의 구역으로 판단한다.

단, 적록색약인 사람은 빨강(R)과 초록(G)을 구분하지 못하므로 두 색을 같은 색으로 취급한다.

**정상인과 적록색약인 사람이 각각 보는 구역의 개수를 구하는 문제이다.**

### 입력
- 첫째 줄에 그리드의 크기 N이 주어진다. (1 ≤ N ≤ 100)
- 다음 N개의 줄에 R, G, B로 구성된 문자열이 주어진다.

### 출력
- 정상인이 보는 구역의 개수와 적록색약인 사람이 보는 구역의 개수를 공백으로 구분하여 출력한다.

## 2. 테스트 케이스

### 테스트 케이스 1 — 기본 예제

**입력**
```text
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

**예상 출력**
```text
4 3
```

### 테스트 케이스 2 — R과 G가 번갈아 등장하는 경우

**입력**
```text
5
RGRGR
GRGRG
RGRGR
GRGRG
RGRGR
```

**예상 출력**
```text
25 1
```

### 테스트 케이스 3 — 다른 색상으로 둘러싸인 구역

**입력**
```text
5
BBBBB
BRRRB
BRGRB
BRRRB
BBBBB
```

**예상 출력**
```text
3 2
```
