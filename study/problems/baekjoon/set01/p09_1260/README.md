# 백준 1260번 - DFS와 BFS

## 1. 문제

그래프를 DFS(깊이 우선 탐색)와 BFS(너비 우선 탐색)로 탐색한 결과를 출력한다.

방문할 수 있는 정점이 여러 개라면 번호가 작은 정점부터 방문하며, 더 이상 방문할 수 있는 정점이 없으면 탐색을 종료한다.

**입력**

- 첫째 줄에 정점의 수 N, 간선의 수 M, 탐색을 시작할 정점의 번호 V가 주어진다. (1 ≤ N ≤ 1,000, 1 ≤ M ≤ 10,000, 1 ≤ V ≤ N)
- 정점에는 1번부터 N번까지 번호가 붙어 있다.
- 다음 M개의 줄에 간선이 연결하는 두 정점의 번호가 주어진다.
- 간선은 양방향이며, 두 정점 사이에 여러 개의 간선이 있을 수 있다.

**출력**

- 첫째 줄에 DFS로 정점을 방문한 순서를 출력한다.
- 둘째 줄에 BFS로 정점을 방문한 순서를 출력한다.
- 각 줄은 V부터 시작하며, 방문한 정점의 번호를 공백으로 구분한다.

## 2. 풀이 방법

**인접 리스트 정렬과 DFS, BFS**를 사용

### 시간 복잡도

전체 시간 복잡도는 **O(N + M log M)**이다.

- N: 정점의 수
- M: 간선의 수

인접 리스트를 구성하는 데 O(N + M), 각 인접 리스트를 정렬하는 데 전체 O(N + M log M)이 걸린다.

DFS와 BFS는 각각 정점과 간선을 탐색하므로 O(N + M)이 걸린다.

따라서 정렬을 포함한 전체 시간 복잡도는 **O(N + M log M)**이다.

### 공간 복잡도

전체 공간 복잡도는 **O(N + M)**이다.

인접 리스트에 O(N + M), 방문 배열과 DFS 재귀 호출 스택, BFS 큐, 탐색 결과를 저장하는 데 각각 O(N)의 공간을 사용하기 때문이다.
