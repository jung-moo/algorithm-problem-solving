# 백준 9663번 - N-Queen

## 1. 문제 내용

N × N 크기의 체스판 위에 퀸 N개를 서로 공격할 수 없도록 배치하는 문제이다.

퀸은 가로, 세로, 대각선 방향으로 이동할 수 있으며, 서로 공격할 수 없도록 배치하는 모든 경우의 수를 구해야 한다.

- **입력:** 체스판의 크기 N (1 ≤ N < 15)
- **출력:** 퀸 N개를 서로 공격할 수 없도록 배치하는 경우의 수

## 2. 문제 등급

- **골드 4 (Gold IV)**

## 3. 문제 유형

- 브루트포스 (완전 탐색)
- 백트래킹 (Backtracking)
- 깊이 우선 탐색 (DFS)

