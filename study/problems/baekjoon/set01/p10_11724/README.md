## 문제

- 난이도: Silver II

방향 없는 그래프가 주어졌을 때, 연결 요소(Connected Component)의 개수를 구하는 프로그램을 작성하시오.

연결 요소란 그래프에서 서로 경로를 통해 도달할 수 있는 정점들의 집합을 의미한다.

다른 정점과 연결되지 않은 고립된 정점도 하나의 연결 요소로 취급한다.

### 입력

첫째 줄에 정점의 개수 N과 간선의 개수 M이 주어진다.

- 1 ≤ N ≤ 1,000
- 0 ≤ M ≤ N × (N - 1) / 2

둘째 줄부터 M개의 줄에 간선의 양 끝점 u와 v가 주어진다.

- 1 ≤ u, v ≤ N
- u ≠ v
- 같은 간선은 한 번만 주어진다.

### 출력

첫째 줄에 연결 요소의 개수를 출력한다.

---

## 테스트 케이스

### 테스트 1. 정점이 하나인 경우

**입력**
```text
1 0
```

**예상 출력**
```text
1
```

### 테스트 2. 간선이 하나도 없는 경우

**입력**
```text
5 0
```

**예상 출력**
```text
5
```
