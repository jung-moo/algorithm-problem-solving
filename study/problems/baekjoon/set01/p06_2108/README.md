
# 백준 2108번 - 통계학

## 1. 문제

N개의 정수가 주어졌을 때, 다음 네 가지 통계값을 구한다.

- **산술평균**: N개의 수의 합을 N으로 나눈 값으로, 소수점 이하 첫째 자리에서 반올림한다.
- **중앙값**: N개의 수를 오름차순으로 정렬했을 때 중앙에 위치하는 값이다.
- **최빈값**: N개의 수 중 가장 많이 나타나는 값이다. 최빈값이 여러 개라면 두 번째로 작은 값을 선택한다.
- **범위**: N개의 수 중 최댓값과 최솟값의 차이다.

**입력**

- 첫째 줄에 정수의 개수 N이 주어진다. (1 ≤ N ≤ 500,000, N은 홀수)
- 둘째 줄부터 N개의 줄에 정수가 하나씩 주어진다.
- 입력되는 정수의 절댓값은 4,000을 넘지 않는다.

**출력**

- 첫째 줄에 산술평균을 출력한다.
- 둘째 줄에 중앙값을 출력한다.
- 셋째 줄에 최빈값을 출력한다.
- 넷째 줄에 범위를 출력한다.

## 2. 풀이 방법 

- 최빈값 구하기: HashMap 을 이용한 풀이

### 시간 복잡도

전체 시간 복잡도는 **O(N log N)**이다.

- 배열 정렬: O(N log N)
- 산술평균 계산: O(N)
- 중앙값 계산: O(1)
- 최빈값 계산: 평균 O(N + K log K)
- 범위 계산: O(1)

여기서 K는 최빈값 후보의 개수이며, K ≤ N이다.

배열 정렬과 최빈값 후보 정렬에 O(N log N)이 소요되므로 전체 시간 복잡도는 **O(N log N)**이다.
