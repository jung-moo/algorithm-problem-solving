# 백준 1715 - 카드 정렬하기

## 1. 문제 내용

N개의 카드 묶음이 주어지고, 각 카드 묶음에는 일정한 개수의 카드가 들어 있다.

두 카드 묶음을 합칠 때 필요한 비교 횟수는 두 묶음에 포함된 카드 개수의 합과 같다.

모든 카드 묶음을 하나로 합칠 때 필요한 **최소 비교 횟수**를 구하는 문제다.

### 입력 조건
- 첫째 줄에 카드 묶음의 개수 N이 주어진다. (1 ≤ N ≤ 100,000)
- 이후 N개의 줄에 각 카드 묶음의 카드 개수가 주어진다.
- 각 카드 묶음의 카드 개수는 1,000 이하의 양의 정수다.

### 출력 조건
- 모든 카드 묶음을 하나로 합치는 데 필요한 최소 비교 횟수를 출력한다.
- 카드 묶음이 하나뿐이라면 0을 출력한다.

## 2. 문제 등급

- **골드 4 (Gold IV)**

## 3. 문제 유형

- **그리디 알고리즘 (Greedy Algorithm)**
- **우선순위 큐 (Priority Queue)**
- **최소 힙 (Min Heap)**
- **최적 병합 패턴 (Optimal Merge Pattern)**

## 4. 테스트 케이스

### 테스트 케이스 1 - 최소 입력 (경계 조건)

**입력**
```text
1
10
```

**예상 출력**
```text
0
```

### 테스트 케이스 2 - 일반적인 카드 병합

**입력**
```text
4
10
20
30
40
```

**예상 출력**
```text
190
```

### 테스트 케이스 3 - 동일한 크기의 카드 묶음

**입력**
```text
8
1000
1000
1000
1000
1000
1000
1000
1000
```

**예상 출력**
