## 1. 문제 내용

**백준 1759번 - 암호 만들기**

서로 다른 C개의 알파벳 중 L개를 선택하여 가능한 모든 암호를 생성하는 문제다.

**조건**
- 암호는 서로 다른 L개의 소문자 알파벳으로 구성된다.
- 모음(a, e, i, o, u)이 최소 1개 포함되어야 한다.
- 자음이 최소 2개 포함되어야 한다.
- 암호에 사용되는 알파벳은 오름차순으로 배치되어야 한다.
- 가능한 모든 암호를 사전순으로 출력해야 한다.

**입력**
- 첫째 줄에 L과 C가 주어진다. (3 ≤ L ≤ C ≤ 15)
- 둘째 줄에 C개의 서로 다른 소문자 알파벳이 주어진다.

**출력**
- 조건을 만족하는 모든 암호를 사전순으로 한 줄씩 출력한다.
