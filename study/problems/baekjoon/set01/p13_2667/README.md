## 문제 설명

- **문제 등급:** 실버 1

정사각형 모양의 지도에서 집이 있는 곳은 `1`, 집이 없는 곳은 `0`으로 표시된다.

상하좌우로 연결된 집들은 하나의 단지로 간주한다. 대각선으로 연결된 집들은 같은 단지로 간주하지 않는다.

지도가 주어졌을 때, 총 단지의 개수를 구하고 각 단지에 속하는 집의 수를 오름차순으로 출력하는 프로그램을 작성하시오.

### 입력

- 첫 번째 줄에 지도의 크기 `N`이 주어진다. (5 ≤ N ≤ 25)
- 다음 N개의 줄에 N개의 숫자(0 또는 1)가 공백 없이 주어진다.

### 출력

- 첫 번째 줄에 총 단지의 개수를 출력한다.
- 두 번째 줄부터 각 단지에 속하는 집의 수를 오름차순으로 한 줄에 하나씩 출력한다.

---

## 테스트 케이스 1

**입력**
```text
7
0110100
0110101
1110101
0000111
0100000
0111110
0111000
```

**출력**
```text
3
7
8
9
```
