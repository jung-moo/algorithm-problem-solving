# 백준 1647번 - 도시 분할 계획

## 1. 문제 내용

N개의 집과 M개의 길이 주어진다. 각 길에는 유지비가 존재하며, 모든 집은 길을 통해 서로 연결되어 있다.

마을을 정확히 두 개로 분리하되, 각 마을 안에서는 모든 집이 서로 연결되어 있어야 한다.

이때 두 마을에 남겨진 길의 유지비 합을 최소화해야 한다.

**입력 조건**
- 첫째 줄에 집의 개수 N과 길의 개수 M이 주어진다.
- 2 ≤ N ≤ 100,000
- 1 ≤ M ≤ 1,000,000
- 다음 M개의 줄에 A, B, C가 주어진다.
    - A, B: 길로 연결된 두 집
    - C: 길의 유지비 (1 ≤ C ≤ 1,000)
- 길은 양방향이며, 모든 집은 서로 연결되어 있다.

**출력 조건**
- 마을을 두 개로 분리했을 때 필요한 최소 유지비 합을 출력한다.

## 2. 문제 등급

- **골드 4 (Gold IV)**

## 3. 문제 유형

- 그래프 (Graph)
- 최소 신장 트리 (Minimum Spanning Tree, MST)
- 프림 알고리즘 (Prim)
- 크루스칼 알고리즘 (Kruskal)
