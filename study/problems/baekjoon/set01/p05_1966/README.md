# 백준 1966번 - 프린터 큐

## 1. 문제

문서의 중요도에 따라 인쇄 순서를 결정하는 프린터가 있다. 큐의 가장 앞에 있는 문서보다 중요도가 높은 문서가 뒤에 하나라도 있으면, 앞의 문서를 인쇄하지 않고 큐의 맨 뒤로 옮긴다. 그렇지 않으면 해당 문서를 인쇄한다.

문서의 개수와 중요도, 확인하려는 문서의 처음 위치가 주어졌을 때, 그 문서가 몇 번째로 인쇄되는지 구한다.

**입력**

- 첫째 줄에 테스트 케이스의 수가 주어진다.
- 각 테스트 케이스의 첫째 줄에 문서의 개수 N과 확인할 문서의 위치 M이 주어진다. (1 ≤ N ≤ 100, 0 ≤ M < N)
- 둘째 줄에 N개 문서의 중요도가 순서대로 주어진다. 중요도는 1 이상 9 이하이며, 같은 중요도의 문서가 여러 개 있을 수 있다.
- 문서의 위치는 큐의 맨 앞을 0으로 센다.

**출력**

- 각 테스트 케이스마다 확인할 문서가 몇 번째로 인쇄되는지 한 줄에 출력한다.

## 2. 풀이 방법

**큐(Queue)를 이용한 시뮬레이션**을 사용

### 시간 복잡도

테스트 케이스당 **O(N²)**이다.

중요도가 1~9로 제한되어 있어 문서를 꺼내고 다시 넣는 횟수는 전체 O(N)이며, 꺼낸 문서마다 큐를 순회하는 데 최대 O(N)이 걸린다.
